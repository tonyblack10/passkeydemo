🔑 Passkey Demo

WebAuthn com Spring Web + webauthn4j — RP ID localhost, origens http://localhost:8080

Verificando o suporte a passkeys deste navegador…

1. Registrar uma passkey

Cria um par de chaves no seu autenticador. Só a chave pública é enviada ao servidor. Usar um username existente adiciona outra passkey a esse usuário.

2. Entrar com passkey

O servidor envia um challenge; o autenticador o assina com a chave privada e o servidor valida a assinatura com a chave pública guardada. Deixe o username em branco para escolher entre as passkeys salvas (credencial descobrível).
